# Установка движка — инструкция для Claude Code

Ты (Claude Code) устанавливаешь пользователю монтажный движок. Пользователь — новичок, в коде не разбирается.
**Всё, что можешь сделать сам, делай сам.** От человека — только то, что физически можешь сделать только он: клик в
системном окне, вход в браузере, ключи. Объясняй простыми словами, одним шагом за раз, без терминов. Перед каждым
действием человека говори коротко: что он увидит и куда нажать. Не проси его открывать Терминал.

Папка движка — эта (обычно `~/.claude/skills/montazh`). Mac или Windows — определи сам (`uname` / `$env:OS`).

## 1. Окружение
1. Запусти `python3 install.py` (Windows: `py install.py` или `python install.py`). Ставит всё без прав администратора
   внутрь `.venv/`: ffmpeg, Node.js, yt-dlp, пакеты Remotion, библиотеки анимаций (~0,5 ГБ, 5–20 минут).
   Медленная загрузка с GitHub в некоторых странах — норма; скажи человеку, что ждём.
2. Есть `✗` — прочитай строку и почини сам. Нет git: Mac — `xcode-select --install` (скажи: «появится окно, нажми
   „Установить“, подожди 5–10 минут»); Windows — `winget install --id Git.Git -e` (скажи: «если спросит разрешение — нажми „Да“»).
   Нет Python на Windows — `winget install -e --id Python.Python.3.12 --scope user`. Потом запусти install.py ещё раз.
3. Все команды движка дальше — с окружением: Mac `source .venv/bin/activate && …`, Windows `.venv\Scripts\activate; …`.

## 2. Проверка, что монтаж работает
`cd шаблон && node stills.mjs ../out/проверка 1 4 8` — три кадра демо-ролика. Покажи человеку один кадр (открой файл)
и скажи: «Движок работает». Первый рендер сам скачает браузер для рендера (~100 МБ) — это нормально.

## 3. Личные настройки (`local.md`)
Спроси по одному вопросу и запиши ответы в `local.md`:
1. Где хранить ролики? Предложи `Документы/Монтаж` и создай папку сам.
2. На каком языке ролики? Кто пишет текст (ты сам или другой сервис)?
3. Что говорить в конце ролика (призыв: «пиши слово … в комментариях»)? Можно «потом».
4. Ник в Instagram для подписи внизу кадра? Можно без него.

## 4. Ключи — только если человек хочет голос и разбор референсов
Без ключей движок монтирует по готовому голосу или без голоса. Предложи: «Хочешь, чтобы я сам озвучивал ролики
и разбирал чужие видео? Понадобятся два бесплатных ключа — это 5 минут». Если да:
1. **Gemini** (бесплатно): скажи открыть **aistudio.google.com/apikey**, войти через Google, нажать **Create API key**, скопировать.
2. **ElevenLabs** (голос): зарегистрироваться на **elevenlabs.io**, открыть **elevenlabs.io/app/settings/api-keys**,
   **Create API Key**, скопировать. Предупреди: на бесплатном тарифе голос нельзя использовать в рекламе и для клиентов.
3. Открой файл ключей сам: Mac `open -e .env`, Windows `notepad .env`. Скажи: «вставь ключи после знака =, без пробелов,
   сохрани (⌘S или Ctrl+S) и закрой». Ключи не проси присылать в чат.
4. Проверь, что ключи читаются (без расхода): `python -c "import sys; sys.path.insert(0,'инструменты'); import _env; print(bool(_env.key('GEMINI_API_KEY')), bool(_env.key('ELEVENLABS_API_KEY')))"`.

## 5. Звуки и музыка
Скачай библиотеку сам (~10 минут, бесплатно, можно в коммерции):
`python инструменты/sfxlib.py fetch whoosh click pop interface bass hit transition`, затем `… sfxlib.py norm`, `… sfxlib.py sheet`,
`python инструменты/musiclib.py fetch tag/technology discover/house`.

## 6. Объясни, как работать (коротко, своими словами)
- «Смонтируй такой же ролик, как тут: <ссылка>» — разберу и соберу похожий.
- «Смонтируй ролик на этот текст: …» — подберу приёмы под каждую фразу.
- Сначала покажу 2–3 кадра, после «да» соберу весь ролик и положу в папку роликов.
- «Сделай сочнее», «поменяй цвет», «быстрее» — правки обычными словами.
- «Обнови движок» — подтяну новые приёмы.

## Обновление (когда человек попросит)
`git pull` в этой папке, потом снова `install.py` (доставит только новое).

## Апгрейды (когда человек попросит)
- **Голос ElevenLabs / разбор роликов Gemini:** как в шаге 4 — объясни, где взять ключ, открой `.env` в редакторе, ключ в чат не проси.
- **Готовые ролики в Telegram:** человек создаёт бота у @BotFather (`/newbot` → имя → ник на `bot` → токен) и жмёт Start у своего бота.
  Открой `.env`, пусть вставит `TELEGRAM_BOT_TOKEN`. Проверка: `python инструменты/telegram.py --text "Движок подключён"`
  (TELEGRAM_CHAT_ID найдётся и запишется сам). Готовое видео: `python инструменты/telegram.py ролик.mp4 "подпись"`.
  Запиши в `local.md`: «Сдача — в Telegram через telegram.py».
