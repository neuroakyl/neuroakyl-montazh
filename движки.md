# Движки и инструменты

Пути — от корня этого репозитория. Где лежат ролики пользователя — в `local.md`.

## Какой движок под что
| Движок | Где | Под что | Сильное | Слабое |
|---|---|---|---|---|
| **Шаблон Remotion** (основной) | `шаблон/` | любой ролик: без лица, с лицом, вставками | React-код, слова по таймингу голоса (`at("слово#2")`), фоны, плашки, каллиграфия, телефон, звук по словам, обложка | 3D и сложные шейдеры — подключать отдельно |
| **Детали шаблона** | `шаблон/src/kit/` | готовые конструкции: текст, схемы, телефон, карточки, календарь | ставятся одной строкой с временами слов; каталог «когда брать» — `приёмы.md` | вид — под палитру/шрифт ролика, раскладку подгонять |
| **Спутниковая карта** | `шаблон/src/kit/sputnik.tsx` | любой рассказ на карте: история, география, «где это было» — всегда она (SKILL.md §1) | глобус → улицы без дрожания, наклейка места с флагом на ветру, камера под углом, примерная область, фото на булавке | только своя карта Земли: вымышленные миры — отдельно |
| **pdoom-video** (MIT, mexicat) | ставится отдельно, см. ниже | моушн-листы без лица: перо, караоке, камера по листу | моушн-блюр, свечение, горизонталь и вертикаль из одного кода | нет работы с видео спикера; three.js + canvas, не React |
| **Remocn** | `внешнее/remocn/` (каталог `remocn-каталог.txt`) | готовые анимации для Remotion | ≈250 штук: текст, субтитры, переходы, шейдерные фоны, UI | пропсы читать в доках, не по памяти |

**Правило выбора:** ролик всегда на шаблоне; на каждую фразу — деталь из `kit/` или приём из `приёмы.md` и `внешнее/` по смыслу.
Моушн-лист без лица с пером и караоке → pdoom. Новый стиль на том же движке: фундамент (рендер, тайминг, камера,
звук) не трогать, меняется слой стиля (палитра, шрифты, набор элементов, сцены).

## Новый ролик на шаблоне
1. Папка ролика — в рабочей папке из `local.md`: `<рабочая>/NN-имя/`. Скопировать `шаблон/` в `NN-имя/движок/`,
   `node_modules` — ссылкой на `<репозиторий>/шаблон/node_modules` (ставит `install.py`, повторно не качаем).
   Ролик живёт в своей папке и движок не меняет: правки шаблона — только осознанно, когда деталь нужна всем.
2. Голос: `python3 -I инструменты/golos.py текст.txt <папка ролика> --voice adam` → `assets/voice.wav`, `words.json`.
   До голоса можно собирать на черновых таймингах: `инструменты/demo_words.py текст.txt движок/src/words.json`.
   Голос и тайминги кладутся в `движок/public/voice.wav` и `движок/src/words.json`, в `src/settings.ts` включить `voice: true`.
3. Якоря слов: `python3 -I инструменты/slova.py движок/src/words.json` — печатает `at("слово#N")` для каждого слова.
4. Кадры для проверки: `cd движок && node stills.mjs ../кадры 1.0 5.2 …`; обложка: `python3 -I <репозиторий>/инструменты/oblozhka.py sdelat` из папки движка (`обложка.md`).
5. Видео: `node render.mjs ../видео.mp4`, звук: `node audio.mjs ../звук.wav`,
   сдача: `python инструменты/deliver.py ../видео.mp4 ../звук.wav ../cover.jpg ../Готово.mp4` (обложка первыми 0,1 с, −14 LUFS).

## Ролик на другом языке по разобранному референсу (21.10.2026, ролик «шаги»)
Сцены и время привязаны к кускам исходного сценария (русские ключи в `T("…")`), на экран и в голос идёт перевод:
1. Перевод построчно (кусок = строка, число строк то же): Claude или сервис, указанный в `local.md` для этого языка;
   ключевое слово строки — в `*звёздочках*` (цвет плашки берётся из исходной строки). Надписи — словарь `ключ → перевод`.
2. Голос по переводу; тайминги слов — `words.py` (MMS). Числа на экране цифрами, в голосе словами — сколько слов в числе,
   учесть при раскладке слов по строкам.
3. Ключи 3D-камеры — через `camAt` (ключи ближе 0,9 с выкидываются): у перевода другая длина фраз.

## Установка (проверено на MacBook M2, 16 ГБ)
Всё основное ставит `python3 install.py` без прав администратора, внутрь `.venv/` (Mac и Windows):
ffmpeg — пакет static-ffmpeg, Node.js — nodeenv, yt-dlp, fonttools, Remotion. Порядок для Claude — `УСТАНОВКА.md`. Дополнительно, по задаче:
| Что | Зачем | Как |
|---|---|---|
| git, Python 3 | основа | Mac — `xcode-select --install` (окно «Установить»); Windows — `winget install Git.Git` и `Python.Python.3.12 --scope user` |
| Remotion 4 | видео кодом | ставит `install.py` в `шаблон/`; бесплатно для соло и команд до 3 человек. Версии всех `@remotion/*` = версии remotion |
| GSAP 3 | анимация текста и форм: SplitText, MorphSVG | `npm i gsap` в проекте ролика |
| three.js + @remotion/three + fiber + drei | 3D, камера, свет | `npm i three @react-three/fiber @react-three/drei @remotion/three` |
| @remotion/motion-blur, lottie, transitions, paths, shapes, noise | блюр, иконки, переходы, линии, фигуры, шум | `npm i @remotion/…` той же версии |
| Demucs | разобрать звук референса на голос / музыку / эффекты | `python3 -m venv .venv-audio && .venv-audio/bin/pip install demucs` |
| torchaudio (MMS) | тайминги слов своей записи, 1100+ языков, кыргызский ±25 мс | `инструменты/words.py`; ставится тяжело (~2 ГБ), нужен только для своей озвучки — ElevenLabs отдаёт тайминги сам |
| yt-dlp | скачать референс | ставит `install.py` в `.venv/`; YouTube может просить куки — `YT_COOKIES` в `.env` |
| bun, Google Chrome | рендер pdoom | bun.sh |

В Remotion анимация только от кадра (`useCurrentFrame`, `interpolate`, `spring`): CSS-анимации и `Math.random()` ломают рендер.

### Грабли
- **Карта в Remotion дрожит** (04.11.2026): живая веб-карта (MapLibre/Mapbox) с `jumpTo` на каждом кадре в рендере мерцает,
  а неподвижная «подложка» не даёт подлёта со страны до города. Поэтому `kit/sputnik.tsx` собирает кадр сам из плиток двух
  уровней с плавной сменой. Глобус — WebGL: рендер с `chromiumOptions: { gl: "angle" }` (уже в `render.mjs`, `stills.mjs`).
  Глобус меняется на плоскую карту, только когда он в 2+ раза больше кадра, иначе по краям «призрак» растянутой карты мира.
- **Б-ролл застывает** (28.10.2026, ночная четвёрка): `OffthreadVideo` без `<Sequence from={начало сцены}>` берёт время всего
  ролика — клип в 4 с на 30-й секунде стоит на последнем кадре, живым остаётся только наезд. Клип всегда внутри Sequence от
  начала сцены, а если он короче сцены с переходом — `playbackRate` = длина клипа / (сцена + 0,4 с), не медленнее 0,5.
  Готовая деталь — `BRoll` в `Ролики/24-стан/движок/src/core.tsx` (длины клипов — `clips.json`). Проверка: два стоп-кадра
  одной сцены через 1 с — картинка внутри клипа должна меняться, а не только масштаб.
- Спутниковая карта одним JPEG 9600×4000 иногда не декодируется в рендере («source image cannot be decoded») — резать на тайлы 2400×2000.
- macOS не различает регистр имён: `reel.ts` и `Reel.tsx` — один файл. Поэтому настройки ролика — `settings.ts`.
- Браузер рендера кэширует шрифт по имени файла: поправил шрифт — меняй имя файла, иначе в кадре старая версия.
- `at("слово")` ищет по началу слова: «танда» ловит «тандап», «нейро» — «нейросеть». Для повторов — `at("танда#2")`,
  для коротких слов — точное совпадение `at("=в")`. Номера печатает `slova.py`.
  **Ловушка сцен** (31.10.2026, ночная пятёрка, три ролика из пяти): якорь сцены цепляется за слово РАНЬШЕ по тексту
  («Көз» → «көзү», «Сууда» → «сууда калкып», «Адамды» → «адамдын», «дарыя» → «дарыядан»). Сцена встаёт не на место,
  а так как текущая сцена — последняя с `t >= a`, весь хвост ролика залипает на одном клипе. Каждый якорь проверять
  по распечатке слов: повторяющийся корень — `at("слово", после_секунды)` или `=слово`; после сборки — лист кадров
  каждые 2–3 с, одинаковые кадры подряд = ловушка.
- Каллиграфии с ң ө ү почти нет (проверено ~25 шрифтов Google). Решение — дорисовать чёрточки: `инструменты/kg_font.py`
  (через `.venv/bin/python`, нужен fontTools). Штрих внутри «о» рисовать против часовой, иначе он вырезается.
- ElevenLabs на кыргызском читает медленно (165 слов ≈ 80 с): под темп референса ускорять готовый голос
  `ffmpeg -i voice.wav -af atempo=1.25 voice-x125.wav` (×1,25 звучит нормально), тайминги слов делить на 1,25.
- **3D (three.js) — чёрный кадр** (27.10.2026, ролик «танк»): 1) `@remotion/three` строго той же версии, что `remotion`
  (`"4.0.533"`, без `^`: npm ставит новее — холст пустой); 2) `@react-three/postprocessing` (EffectComposer) в рендере даёт
  чёрный холст — свечение и виньетку делать CSS поверх. Рендер 3D — `chromiumOptions: { gl: "angle" }`, ~2 мин на 2 минуты ролика.
- `deliver.py`: картинка-обложка зациклена, поэтому у overlay стоит `shortest=1` — иначе в конце висит застывший кадр.

## Инструменты (`инструменты/`)
Ключи — в `.env` корня (образец `.env.example`). Запуск: `python3 -I инструменты/<файл>.py …`.
| Файл | Что делает |
|---|---|
| `smotret.py` | разбор референса: кадр в секунду листами, склейки, разбор Gemini (`watch.py`) |
| `tz-gemini.md` | ТЗ глубокого разбора: картинка шот за шотом + звук |
| `watch.py` | Gemini смотрит видео целиком (бесплатный дневной лимит) |
| `golos.py` | голос ElevenLabs с таймингом каждой буквы → `words.json`; теги эмоций v4 `[excited]`. Через API на бесплатном тарифе — только встроенные голоса (Adam, Brian…), коммерция — с тарифа Starter |
| `demo_words.py` | черновые тайминги без голоса — собрать монтаж до озвучки |
| `slova.py` | якоря слов `at("слово#N")` для сцен |
| `broll.py` | Б-роллы с YouTube и Pinterest: поиск, отрезок, лист превью для выбора глазами |
| `sfxlib.py`, `musiclib.py` | скачать библиотеку эффектов и музыки Mixkit (бесплатно, коммерция можно), выровнять громкость, каталог |
| `audition.py` | склеить кандидатов звука в дорожку с картой «№ → секунда» для слепой прослушки Gemini |
| `words.py` | тайминги слов своей записи (MMS), см. установку |
| `kg_font.py` | дорисовать ө Ө ң Ң в шрифт без кыргызских букв |
| `deliver.py` | сдача: обложка первыми 0,1 с, −14 LUFS; без обложки не сдаёт |
| `oblozhka.py` | обложка: стиль ленты, кадры с лицом, вырезание (Vision / rembg), поиск картинок, 3D-эмодзи, сборка и проверка (`обложка.md`) |
| `karta.py` | материалы спутниковой карты: `globus` (текстура Земли 8K), `granica "Talas Region"` (граница из OpenStreetMap), `tochka` (координаты места), `kartinka "Flag of ….svg"` (флаг, герб, фото с Commons, `--poisk`) |
| `telegram.py` | готовое видео себе в Telegram через своего бота (`TELEGRAM_BOT_TOKEN` в `.env`, больше 50 МБ — сожмёт копию) |

## Звук и музыка
- Своя библиотека: `python3 -I инструменты/sfxlib.py fetch whoosh click pop interface bass hit transition`
  → `python3 -I инструменты/sfxlib.py norm` → `sheet` (каталог). Музыка: `musiclib.py fetch tag/technology discover/house`.
  Лежит в `MONTAZH_LIB` (`.env`), по умолчанию `<репозиторий>/библиотека/` — в Git не попадает.
- Файлы звуков и музыки в репозиторий не кладём. Sonniss прямо запрещает раздавать звуки отдельными файлами
  (только внутри своего проекта); официальный текст Mixkit про раздачу не проверен (17.10.2026), поэтому тоже не кладём —
  каждый качает себе скриптом. Mixkit режет частые запросы — скрипт делает паузы 4+ с.
- Sonniss GDC (бесплатные паки, коммерция без указания автора): сайт за Cloudflare — качать руками.

## pdoom-video (моушн-листы без лица)
Ставится отдельно: `git clone https://github.com/mexicat/pdoom-video` в рабочую папку, сначала собрать ролик автора у себя.
1. Голос → `audio/voiceover.mp3`; слова с таймингом → `data/lyrics.json`.
2. Одна сцена = один файл `app/src/scenes/*.ts`: в `init()` штрихи пера, караоке-строки и ключи камеры по времени слов
   (`wordOf(line, 'слово').start`), в `render()` — удары: вспышка, зум, тряска.
3. Сцена в `app/src/timeline.ts`: склейка в паузе перед строкой (`cut('первые слова строки')`).
4. Общая база стиля в одном файле (удары на весь кадр, проявляющаяся строка, печать чата/кода, удары камеры, уход групп);
   сцена-наследник только раскладывает свою картинку — так 10+ сцен держат один стиль.
5. Вставки-клипы: кадры `app/public/ins/<имя>/0001.jpg…` (`ffmpeg -ss <с> -t <длит> -i <файл> -vf "fps=30,scale=…" ins/<имя>/%04d.jpg`).
6. Два формата: `hv(горизонталь, вертикаль)` в каждой сцене; флаг `--fmt v` → 1080×1920. Обрезать горизонталь нельзя.
7. Проверка кадрами: `bun scripts/render.ts stills --url http://localhost:1 --t 9.6,12.9 --out ../out/проверка`.
8. Видео: `bun scripts/render.ts video --from 0 --to 19.3 --samples auto --shutter 0.5 --crf 17 --noaudio`, звук склеить ffmpeg.
Грабли: вспышка на ударе живёт 1–2 кадра, иначе чёрный сереет. Кыргызские буквы в регулярке слов: `[^a-z0-9а-яңөү()]`.

## Remocn: как подключить
1. В проекте Remotion: `npx shadcn@latest add @remocn/<имя>` → код ложится в `components/remocn/`, он наш, правим как хотим.
   Или скопировать компонент из `внешнее/remocn/registry/remocn/<имя>/`.
2. Перед выбором — `remocn-каталог.txt` (или свежий `https://remocn.dev/llms-components.txt`): «когда брать / когда нет».
3. Пропсы — только из `https://remocn.dev/docs/<раздел>/<имя>.md`, не по памяти.
4. Субтитры Remocn работают от `captions: Caption[]` — наш `words.json` переводится в этот формат.
