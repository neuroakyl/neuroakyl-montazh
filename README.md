# NeuroAkyl · монтаж роликов с Claude Code

Навык, который учит Claude Code монтировать Reels и Shorts **кодом**: моушн-графика, слова по голосу, инфографика,
телефоны, таблицы, звук, обложка. Без монтажной программы. Сделан на реальных роликах и правках автора — Боба (NeuroAkyl).

Что внутри:
- **правила вкуса и порядок работы** (`SKILL.md`): как разобрать референс, выбрать стиль, собрать и проверить ролик;
- **шаблон** (`шаблон/`): пустой проект ролика на Remotion — фоны, шрифты с кыргызскими ң ө ү, слова по таймингу голоса, плашки, звук, обложка;
- **детали монтажа** (`шаблон/src/kit/`): готовые анимации-конструкции — заголовок по словам, календарь из хаоса, майндмэп,
  телефон со счётчиком просмотров, сетка карточек с выбором, таблица по словам, стопка строк, большое слово со «смазом».
  Движок берёт их по смыслу фразы (каталог «когда брать» — `приёмы.md`);
- **инструменты** (`инструменты/`): разбор референса через Gemini, голос ElevenLabs, Б-роллы с YouTube, библиотека звуков, сдача;
- **библиотеки приёмов** (`приёмы.md`, `ремесло.md`, `стили.md`) и 14 открытых наборов анимаций (ставятся установщиком).

## Установка — одной фразой в Claude Code (Mac и Windows)

1. Поставь приложение Claude (claude.com/download), войди, открой вкладку **Code**.
2. Напиши: **«Установи монтажный движок: https://github.com/neuroakyl/neuroakyl-montazh»**.
3. Делай только то, о чём попросит Claude: нажать «Установить» или «Да» в системном окне, при желании вставить ключи
   голоса. Всё остальное Claude поставит сам — без Терминала, без аккаунта GitHub и без пароля администратора
   (ffmpeg и Node.js ставятся внутрь папки движка).

Пошаговый гайд с картинками — у автора.

### Для Claude Code: как установить
Пользователь — новичок. Всё, что можешь, делай сам; от человека — только клики в системных окнах. Говори просто,
одним шагом за раз, на языке пользователя (кыргызский или русский).
1. Определи Mac или Windows. Проверь `git --version`.
   - Mac, git нет: `xcode-select --install` и скажи: «Появится окно — нажми „Установить“ и подожди 5–10 минут».
     Дождись, пока `xcode-select -p` вернёт путь.
   - Windows, git нет: `winget install --id Git.Git -e --accept-source-agreements --accept-package-agreements`
     («если Windows спросит разрешение — нажми „Да“»). Python нет — `winget install -e --id Python.Python.3.12 --scope user`.
2. Скачай движок: `git clone https://github.com/neuroakyl/neuroakyl-montazh ~/.claude/skills/montazh`
   (Windows: `%USERPROFILE%\.claude\skills\montazh`). Папка уже есть — `git pull` в ней.
3. Открой `~/.claude/skills/montazh/УСТАНОВКА.md` и выполни его по шагам.
4. В конце скажи: «Готово. Перезапусти приложение Claude, чтобы оно увидело движок».

## Как пользоваться
Просто пиши Claude Code обычными словами:
- «Смонтируй такой же ролик, как тут: <ссылка на Reels>» — разберёт референс и соберёт похожий;
- «Смонтируй ролик на этот текст» — сам подберёт стиль и приёмы под смысл каждой фразы;
- «Сделай монтаж лучше» — пройдёт чек-лист из `SKILL.md`.

Сначала Claude покажет 2–3 стоп-кадра, после твоего «да» соберёт ролик целиком.

## Обновление
Скажи Claude «обнови движок» (или `git pull` и `python3 install.py` в папке движка). Движок растёт: новые детали, приёмы и починенные грабли. Сами ролики автора в репозиторий не попадают.

## Безопасность
- В репозитории только инструкции и код. Нет роликов, сценариев, голосов, материалов заказчиков и ключей.
- Твои ключи (`.env`), настройки (`local.md`), видео и звук в Git не попадают (`.gitignore`).
- Перед каждым коммитом проверка `.githooks/pre-commit` ищет ключи, токены и личные пути и не пропускает их.
  Свои личные слова (ник, имена клиентов) добавь в `.githooks/stop-words.local`.
- Открытые библиотеки скачиваются из оригинальных репозиториев в зафиксированных версиях; что каждая делает и как
  проверена — `внешнее/паспорта/`. Ничего из них не запускается само.
